# Vio Vision Demo Frontend (Next.js + TypeScript)

Este directorio (`web/`) será el nuevo frontend serio basado en Next.js + TypeScript con el diseño dark que definiste.

Mientras tanto, la demo original de Streamlit sigue viviendo en la raíz de la repo (`app.py`, etc.).

Pendiente por mi parte (Lab):

```bash
cd web
```

para levantar el nuevo frontend.
